## About Me

Hi, I'm **Seniru Aluthge**, a software developer and undergraduate at the Institute of Computer Engineering Technology (ICET), Sri Lanka.

I build AI-powered products across the stack, from Python backends to web and mobile clients. I'm especially interested in projects that bring together voice, real-time data, and 3D experiences.

| Currently building | Currently studying |
|:---|:---|
| 🤖 **Aariya** — an autonomous multi-agent AI platform | ☕ Java |
| 🧑‍💼 **HUMANA** — AI digital employees for business websites | 🗄️ SQL and database management |
| 🌌 An interactive 3D portfolio with React, Three.js, and GSAP | 🧱 Software engineering fundamentals |
